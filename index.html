  • Journey: Started July 2023 with Java learning repos (MySecondGit, NewGit, QuizApplication), then a long gap with no new repos in 2024–2025, then a return in Aug–Nov 2026 focused on AWS, Jenkins, Nginx and 3-tier web projects.

  • Complexity: Project scope has increased — from single-file Java practice in 2023 to multi-component 3-tier and CI/CD projects in 2026. Complexity is judged from repo names/descriptions, not from commit counts, which are unavailable.
  • Consistency: Not consistent. The evidence is burst activity in Oct–Nov 2026 (20 of 25 repos in about 7 weeks). Sustained, spaced practice would be stronger evidence than a burst.
  • Visibility gap: 0 stars, 0 forks received, 0 watchers and 1 follower across all 25 repos. That is the biggest portfolio risk — the work exists, but it is not yet discoverable or endorsed.
  • Documentation gap: Only 5 of 25 repos have a description in the API data (AWS-BY-SN, AWS-Projects, Jenkins-Project, saas-landing-page, and the profile repo note in app.js). Add a README and a description to every repo, starting with AWS-Projects, 3-Tier-Web-Project-by---SW and Jenkins-Netflix-Project.
  • Missing skills in the portfolio: No repos in this dataset are categorised as Docker & Containerization, Kubernetes, Infrastructure as Code (Terraform/CloudFormation), Python Programming, or Monitoring & Observability. Those are the clearest gaps for a Cloud/DevOps target role.
  • Portfolio highlights: 3-Tier-Web-Project-by---SW, AWS-Projects, Jenkins-Project (Netflix + CI/CD), Production-Outage-Question-Book, and TCO-CapEx-OpEx-Visual — they best demonstrate practical AWS/DevOps thinking.

How to add LinkedIn data

  1. Export your official LinkedIn analytics.
  2. Copy the values into data/linkedin_template.csv (columns: date, post_title, category, impressions, reactions, comments, reposts, followers, profile_views, search_appearances).
  3. Run python linkedin_import.py — it writes data/linkedin_summary.json and will refuse to invent data if the file is empty or missing.
  4. Categories to use: AWS, DevOps, Docker, Kubernetes, Jenkins, Linux, Python, Cloud Projects, Learning Journey, Career Development.
